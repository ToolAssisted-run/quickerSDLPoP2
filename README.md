# quickerSDLPoP2

quickerSDLPoP2 is the game logic of *Prince of Persia 2: The Shadow and the Flame* (DOS) as a single C++ header, made for tool-assisted speedrunning with [JaffarPlus](https://github.com/ToolAssisted-run/jaffarPlus).

It is the game logic of [SDLPoP2](https://github.com/ToolAssisted-run/SDLPoP2), turned into one class. Every instance owns a whole game, so any number of them can run at once, on any threads. There is no drawing or sound: just the game ticking along, with savestates.

You need your own copy of the original game's files (DOS version 1.0).

## Using it

    #include "quickerSDLPoP2.hpp"

    quicker::QuickerSDLPoP2 game;
    game.initialize("path/to/prince2");   // the folder with PRINCE.EXE
    game.newGame(1, seed);                // level 1..14, a random seed
    game.advance(1, 0, 0, false);         // one tick: right held (x, y, Shift/Ctrl, a key pressed)

A savestate is the `QuickerSDLPoP2State` part of the object: 23,440 bytes, byte for byte the same as SDLPoP2's own savestate. `saveState` and `loadState` take jaffarCommon's serializers.

`source/quickerSDLPoP2/quickerInstance.hpp` wraps it for JaffarPlus, with the input strings `|K|LRUDSC|`: K a key pressed, the four directions, S Shift, C Ctrl.

## How it is made

`quickerSDLPoP2.hpp` is generated by `tools/generate.py` from SDLPoP2's sources in `extern/SDLPoP2`. Don't edit it by hand: change the generator, or its hand-written parts in `tools/overrides.py`, and run it again.

The generator turns every global variable into a member, and puts the savestate's variables in one packed struct in the same order and size as SDLPoP2 saves them. The few routines the game logic calls from SDLPoP2's program shell are replaced by what they do in the headless core.

When SDLPoP2 changes, update the submodule and run `python3 tools/generate.py`.

## Tests

SDLPoP2 itself is the oracle. Every test movie is played on both, and the final savestates must be identical, in three ways of playing:

- **Simple**: one tick after another.
- **Rerecord**: load, tick, save for every input, as JaffarPlus does.
- **Full**: the same plus an extra tick that is thrown away.

There are 55 movies. They cover every level, every level transition, and the places random play rarely reaches, like level 5's bridge and level 14's final rooms. Another test plays them all at once on 64 threads.

The tests need the game's files:

    meson setup build -DgamePath=path/to/prince2
    meson compile -C build
    meson test -C build

To make new movies, see `tests/makeMovies.sh` and `tests/makeStateMovies.sh`.
